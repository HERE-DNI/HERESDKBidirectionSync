    <div class="platform-hinted " data-platform-hinted="data-platform-hinted"><div class="content sourceset-dependent-content" data-active="" data-togglable=":modules:dokkaHtml/release"><div class="symbol monospace"><span class="token keyword">class </span><a href="index.html">RoutingOptions</a></div><p class="paragraph">The options defines how a route should be calculated.</p><p class="paragraph">The options are used for all transport modes and engines.</p><p class="paragraph">** Electric vehicle specific requirements ** Electric vehicle consumption are estimated when at least one consumption model is defined. Currently two models are supported:</p><ul><li><p class="paragraph">PhysicalConsumptionModel Aside from the values in PhysicalConsumptionModel additionally these values needs to be defined:</p></li><li><p class="paragraph"><a href="../../com.here.sdk.transport/-vehicle-specification/current-weight-in-kilograms.html">com.here.sdk.transport.VehicleSpecification.currentWeightInKilograms</a> from <a href="../../com.here.sdk.transport/-transport-specification/vehicle-specification.html">com.here.sdk.transport.TransportSpecification.vehicleSpecification</a>     from <a href="transport-specification.html">com.here.sdk.routing.RoutingOptions.transportSpecification</a></p></li><li><p class="paragraph">Additionally <a href="../-waypoint/current-weight-change-in-kilograms.html">com.here.sdk.routing.Waypoint.currentWeightChangeInKilograms</a> can be defined.</p></li><li><p class="paragraph">EmpiricalConsumptionModel</p></li></ul><p class="paragraph">By setting <a href="../-electric-vehicle-options/ensure-reachability.html">com.here.sdk.routing.ElectricVehicleOptions.ensureReachability</a> the <code class="lang-kotlin">RoutingEngine</code> inserts additional charging stations to reach the waypoints. This feature requires setting the <a href="../-battery-specifications/index.html">com.here.sdk.routing.BatterySpecifications</a>. By default a vehicle might not reach the waypoint, when the initial charge is not enough to reach all waypoints. See the parameter description below for more details.</p></div></div>
