<h1>CatalogConfiguration class</h1></div>

<p>Using this class you can configure in the <a href="sdk-for-flutter-explore-core-engine-sdkoptions-class">SDKOptions</a>,
how the <a href="sdk-for-flutter-explore-core-engine-sdknativeengine-class">SDKNativeEngine</a> should access, use and store the data for the desired catalog.</p>
<p>Using this class, you can access default catalogs on the HERE platform and also custom catalogs
such as for self-hosted or BYOD (bring your own data) use cases.</p>
<p>For information on how the user can identify a catalog on the HERE platform, see <a href="sdk-for-flutter-explore-core-engine-desiredcatalog-class">DesiredCatalog</a>
For further information about catalogs and related concepts see <a href="sdk-for-flutter-explore-core-engine-catalogidentifier-class">CatalogIdentifier</a>.</p>
<p><strong>Note:</strong>
This API is only applicable for the Navigate license.</p>
