<p>Interface for managing a map layer.
A map layer can be created by using the <code><a href="../Classes/MapLayerBuilder.html">MapLayerBuilder</a></code>. At creation, the layer
gets added to a map. The layer gets removed from the map upon instance destruction.</p>
