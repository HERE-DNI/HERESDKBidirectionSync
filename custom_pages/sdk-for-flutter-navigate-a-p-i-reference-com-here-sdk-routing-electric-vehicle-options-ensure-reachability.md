Requires valid <code class="lang-kotlin">battery_specifications</code>. It also requires that <a href="../-route-options/optimization-mode.html">com.here.sdk.routing.RouteOptions.optimizationMode</a> = <a href="../-optimization-mode/-f-a-s-t-e-s-t/index.html">com.here.sdk.routing.OptimizationMode.FASTEST</a>, <a href="../-route-options/speed-cap-in-meters-per-second.html">com.here.sdk.routing.RouteOptions.speedCapInMetersPerSecond</a> is not set, and <a href="../-avoidance-options/index.html">com.here.sdk.routing.AvoidanceOptions</a> is empty. It is especially useful for longer routes, because after all, charging stations are much less common than petrol stations.</p><p class="paragraph"><strong>Note</strong> An <a href="../-routing-error/-i-n-v-a-l-i-d_-p-a-r-a-m-e-t-e-r/index.html">com.here.sdk.routing.RoutingError.INVALID_PARAMETER</a> is generated when this option is set to <code class="lang-kotlin">true</code> in case <code class="lang-kotlin">sdk.routing.RoutingEngine.import_route</code> is called.
