# <span class="kind-library">animation</span> library

</div>

## Classes

<span class="name"><a href="sdk-for-flutter-explore-animation-anchor2dkeyframe-class">Anchor2DKeyframe</a></span>  
An Anchor2D keyframe.

<span class="name"><a href="sdk-for-flutter-explore-animation-animationlistener-class">AnimationListener</a></span>  
A listener for animation events.

<span class="name"><a href="sdk-for-flutter-explore-animation-easing-class">Easing</a></span>  
Animation easing representing an easing function to be used during animations.

<span class="name"><a href="sdk-for-flutter-explore-animation-geocoordinateskeyframe-class">GeoCoordinatesKeyframe</a></span>  
A GeoCoordinatesKeyframe consists of a GeoCoordinates and an animation duration.

<span class="name"><a href="sdk-for-flutter-explore-animation-geoorientationkeyframe-class">GeoOrientationKeyframe</a></span>  
A GeoOrientationKeyframe consists of a GeoOrientation (camera orientation) and an animation duration.

<span class="name"><a href="sdk-for-flutter-explore-animation-mapitemkeyframetrack-class">MapItemKeyFrameTrack</a></span>  
Stores keyframes for interpolation of a map item property using a specific easing function and interpolation mode.

<span class="name"><a href="sdk-for-flutter-explore-animation-mapmarkeranimation-class">MapMarkerAnimation</a></span>  
An animation that can be applied to the <a href="sdk-for-flutter-explore-mapview-mapmarker-class">MapMarker</a> object.

<span class="name"><a href="sdk-for-flutter-explore-animation-mappolylineanimation-class">MapPolylineAnimation</a></span>  
An animation that can be applied to the <a href="sdk-for-flutter-explore-mapview-mappolyline-class">MapPolyline</a> object.

<span class="name"><a href="sdk-for-flutter-explore-animation-point2dkeyframe-class">Point2DKeyframe</a></span>  
A Point2D keyframe.

<span class="name"><a href="sdk-for-flutter-explore-animation-scalarkeyframe-class">ScalarKeyframe</a></span>  
A ScalarKeyframe consists of a scalar value (e.g,: distance in meters) and an animation duration.

## Enums

<span class="name"><a href="sdk-for-flutter-explore-animation-animationstate">AnimationState</a></span>  
Describes the possible states of an animation.

<span class="name"><a href="sdk-for-flutter-explore-animation-easingfunction">EasingFunction</a></span>  
Animation easing functions.

<span class="name"><a href="sdk-for-flutter-explore-animation-easinginstantiationerrorcode">EasingInstantiationErrorCode</a></span>

<span class="name"><a href="sdk-for-flutter-explore-animation-keyframeinterpolationmode">KeyframeInterpolationMode</a></span>

<span class="name"><a href="sdk-for-flutter-explore-animation-mapitemkeyframetrackinstantiationerrorcode">MapItemKeyFrameTrackInstantiationErrorCode</a></span>  
Describes a reason for failing to create a <a href="sdk-for-flutter-explore-animation-mapitemkeyframetrack-class">MapItemKeyFrameTrack</a>.

<span class="name"><a href="sdk-for-flutter-explore-animation-mapmarkeranimationinstantiationerrorcode">MapMarkerAnimationInstantiationErrorCode</a></span>  
Describes a reason for failing to create a <a href="sdk-for-flutter-explore-animation-mapmarkeranimation-class">MapMarkerAnimation</a>.

<span class="name"><a href="sdk-for-flutter-explore-animation-mappolylineanimationinstantiationerrorcode">MapPolylineAnimationInstantiationErrorCode</a></span>
