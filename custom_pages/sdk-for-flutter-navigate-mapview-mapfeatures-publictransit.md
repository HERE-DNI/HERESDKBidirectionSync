        publicTransit
<div class="features">final</div>

<section class="desc markdown">
<p>Toggles the display of public transit lines for systems like subway, tram, train, monorail,
and ferry, based on the selected mode.</p>
<p>Supported modes: /sdk-for-flutter-navigate-mapview-mapfeaturemodes-publictransitall, /sdk-for-flutter-navigate-mapview-mapfeaturemodes-publictransitasia.</p>
<p>/sdk-for-flutter-navigate-mapview-mapfeaturemodes-publictransitasia is supported only when credentials enabled for the
enriched Japan map are used.</p>
<p>Public transit is disabled by default for all map
schemes when using Rest-of-World map data. When using enriched Japan map
data, public transit is enabled by default with
/sdk-for-flutter-navigate-mapview-mapfeaturemodes-publictransitasia on normal, lite and topo schemes
(including their hybrid variants) and disabled by default on logistics
schemes.</p>
<p>Not supported for /sdk-for-flutter-navigate-mapview-mapscheme, /sdk-for-flutter-navigate-mapview-mapscheme
and /sdk-for-flutter-navigate-mapview-mapscheme.</p>
<p>Note: This is a beta release of this feature, so there could be a few bugs and unexpected
behavior. Related APIs may change for new releases without a deprecation process.</p>
</section>
