Initialization of the HERE SDK itself does not require an internet connection. Returns <code class="lang-kotlin">true</code> if the HERE SDK uses offline connection mode, otherwise returns <code class="lang-kotlin">false</code>.</p><p class="paragraph">Note: This is a <strong>beta</strong> release of this feature, so there could be a few bugs and unexpected behaviors.
