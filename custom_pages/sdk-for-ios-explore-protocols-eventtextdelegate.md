# EventTextDelegate

<div class="declaration">

<div class="language">

``` highlight
public protocol EventTextDelegate : AnyObject
```

</div>

</div>

This protocol should be implemented in order to receive notifications when text notifications are available from <a href="sdk-for-ios-explore-classes-navigator">`Navigator`</a>. Multiple notifications can be given for the same maneuver at different distances.
