<h1>MapMarkerTextStyle constructor</h1></div>

MapMarkerTextStyle()
    

<p>Creates a default set of styling options for the text of a <a href="/sdk-for-flutter-explore-mapview-mapmarker-class">MapMarker</a> that consists of
the following values:</p>
<ul>
<li>Text size: 18 pixels</li>
<li>Text color: opaque white</li>
<li>Text outline size: 0 pixels</li>
<li>Text outline color: opaque black</li>
<li>Text placement: <a href="/sdk-for-flutter-explore-mapview-mapmarkertextstyleplacement">MapMarkerTextStylePlacement.bottom</a></li>
</ul>
<p>Once the resulting <code>TextStyle</code> is applied to a <code>MapMarker</code>, its text will be centered over its
image.</p>
<p>The font will be 18 pixels wide, colored opaque white and will have no visible outline.</p>
