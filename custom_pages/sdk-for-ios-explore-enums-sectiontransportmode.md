# SectionTransportMode

<div class="declaration">

<div class="language">

``` highlight
public enum SectionTransportMode : UInt32, CaseIterable, Codable
```

</div>

</div>

Specifies the <a href="sdk-for-ios-explore-classes-section">`Section`</a> mode of transport. A <a href="sdk-for-ios-explore-classes-section">`Section`</a> may have a different transport mode than the one specified for route calculation. For example, a car route may have a section having ferry transport mode.
