If offline maps are updated, the cache will be also updated. The cache version will never be older than the offline maps version.</p><p class="paragraph">When it is true, the cache will be automatically updated to use the latest map data that is available. In that case, the cache may contain map data that is newer than the offline maps data. Note that auto updates may also lead to increased network traffic, as the cached data will be evicted tile-by-tile before it is filled with newer map data. This process continues everytime the user views a new map view area until the data is replaced. Once also the offline map data is updated by the user, both map versions will be the same again.</p><p class="paragraph">If the value is also specified via the manifest (Android) or plist (iOS), than the value set via <code class="lang-kotlin">SDKOptions</code> will overrule the value that was set in manifest/plist - until the current session ends and the value is read/set again.</p><p class="paragraph">Note that offline maps are only available for the Navigate license.</p><p class="paragraph">Defaults to <code class="lang-kotlin">false</code>.</p><p class="paragraph"><strong>Note:</strong> Do not use this yet, the behavior of this feature may be inconsistent. Once it will be usable, it will be announced in the regular HERE SDK release notes.</p></div></div>
