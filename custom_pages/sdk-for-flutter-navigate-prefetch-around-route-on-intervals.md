To prefetch the whole route before navigation has been started see <a href="sdk-for-flutter-explore-prefetch-geo-corridor">com.here.sdk.prefetcher.RoutePrefetcher.prefetchGeoCorridor</a>. Map data is prefetched only in discrete intervals. Prefetching starts 1 km before reaching the end of the current corridor. Prefetching happens based on the current map-matched location - as indicated by the <a href="sdk-for-flutter-explore-index">com.here.sdk.navigation.RouteProgress</a> event.
