# DynamicRoutingEngineOptions

<div class="declaration">

<div class="language">

``` highlight
public struct DynamicRoutingEngineOptions : Hashable
```

</div>

</div>

Options defining the behavior of the <a href="sdk-for-ios-explore-classes-dynamicroutingengine">`DynamicRoutingEngine`</a>. Both, `minTimeDifference` and `minTimeDifferencePercentage`, will be checked: When the poll interval is reached, the smaller difference will win and the <a href="sdk-for-ios-explore-protocols-dynamicroutingdelegate">`DynamicRoutingDelegate`</a> is notified.
