# <span class="kind-class">FuelStation</span> class

</div>

<div class="section desc markdown">

Contains information about a specific fuel station.

Use <a href="sdk-for-flutter-explore-search-placecategory-businessandservicespetrolgasolinestation">PlaceCategory.businessAndServicesPetrolGasolineStation</a> to find fuel stations. In the `Details` of a `Place` result you can find the associated fuel station information, if any.

**Note:** This is a beta release of this feature, so there could be a few bugs and unexpected behaviors. Related APIs may change for new releases without a deprecation process.
