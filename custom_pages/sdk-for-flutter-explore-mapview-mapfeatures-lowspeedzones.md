<div class="section desc markdown">

City areas designated as low speed zones. Only available when Japan map is used.

Supports only one mode: <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-lowspeedzonesall">MapFeatureModes.lowSpeedZonesAll</a>.

Not supported for <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.satellite</a>, <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.roadNetworkDay</a> and <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.roadNetworkNight</a>. By default, this map feature is not enabled.
