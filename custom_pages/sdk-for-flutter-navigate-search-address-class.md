<h1>Address class</h1></div>

<p>Information about the address of a location.</p>
<p>Used in <a href="sdk-for-flutter-navigate-search-place-address">Place.address</a>.</p>
<p>Note that while <code>OfflineSearchEngine.suggest</code> and <code>OfflineSearchEngine.suggestByText</code> set all available details,
<code>SearchEngine.suggest</code> and <code>SearchEngine.suggestByText</code> set only <a href="sdk-for-flutter-navigate-search-address-addresstext">Address.addressText</a>.
Complete address details can be obtained by searching with <a href="sdk-for-flutter-navigate-search-placeidquery-class">PlaceIdQuery</a>.</p>
