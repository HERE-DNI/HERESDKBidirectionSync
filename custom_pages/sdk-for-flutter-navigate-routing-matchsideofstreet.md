# <span class="kind-enum">MatchSideOfStreet</span> enum

</div>

<div class="section desc markdown">

Specifies how the location set by <a href="sdk-for-flutter-navigate-routing-waypoint-sideofstreethint">Waypoint.sideOfStreetHint</a> should be handled.

This setting might affect the geometry of the resulting route.

</div>

## Values

<span class="name">always</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-routing-matchsideofstreet">MatchSideOfStreet</a></span>  
Always prefer the given side of street regardless if the street has dividers. Use this value if you know that the user is willing to take a longer route in order to ensure arriving at the correct side of the street.

<span class="name">onlyIfDivided</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-routing-matchsideofstreet">MatchSideOfStreet</a></span>  
Only prefer using side of street set by street hint in case the street has dividers. This is the default setting and it is recommended for most use cases.
