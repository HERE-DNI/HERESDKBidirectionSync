# DynamicRoutingDelegate

<div class="declaration">

<div class="language">

``` highlight
public protocol DynamicRoutingDelegate : AnyObject
```

</div>

</div>

This protocol should be implemented in order to receive notifications about the new route via the <a href="sdk-for-ios-explore-classes-dynamicroutingengine">`DynamicRoutingEngine`</a>.

  <div class="abstract">

  This event is issued when a better route could be found, as defined by <a href="sdk-for-ios-explore-structs-dynamicroutingengineoptions">`DynamicRoutingEngineOptions`</a>. To find a better route, two routes are calculated. The updated current route: A route that is calculated via the route specified. The dynamic route: A route that starts at the current position on the route specified and passes through the remaining waypoints.

  </div>
