<h1>CatalogVersionHint class abstract</h1></div>
<section class="desc markdown">
<p>This is a class for capturing user's intent for the
desired catalog version to use in /sdk-for-flutter-navigate-core-engine-desiredcatalog-class class.</p>
<p>You can request a specific or latest version of a catalog by calling the
static functions /sdk-for-flutter-navigate-core-engine-catalogversionhint-specific and
/sdk-for-flutter-navigate-core-engine-catalogversionhint-latestwithignoringcacheddata respectively. The HERE platform will make the
best effort to provide an appropriate version for the catalog based on this
version hint.
Please take note that for the API /sdk-for-flutter-navigate-core-engine-catalogversionhint-specific to function properly,
it is essential that the mutable and persistent storage should be cleaned.</p>
