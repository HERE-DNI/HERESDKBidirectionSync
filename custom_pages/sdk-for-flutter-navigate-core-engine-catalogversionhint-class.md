<h1>CatalogVersionHint class abstract</h1></div>

<p>This is a class for capturing user's intent for the
desired catalog version to use in <a href="/sdk-for-flutter-navigate-core-engine-desiredcatalog-class">DesiredCatalog</a> class.</p>
<p>You can request a specific or latest version of a catalog by calling the
static functions <a href="/sdk-for-flutter-navigate-core-engine-catalogversionhint-specific">CatalogVersionHint.specific</a> and
<a href="/sdk-for-flutter-navigate-core-engine-catalogversionhint-latestwithignoringcacheddata">CatalogVersionHint.latestWithIgnoringCachedData</a> respectively. The HERE platform will make the
best effort to provide an appropriate version for the catalog based on this
version hint.
Please take note that for the API <a href="/sdk-for-flutter-navigate-core-engine-catalogversionhint-specific">CatalogVersionHint.specific</a> to function properly,
it is essential that the mutable and persistent storage should be cleaned.</p>
