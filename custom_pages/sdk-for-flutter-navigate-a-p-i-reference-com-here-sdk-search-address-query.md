A <a href="query.html">com.here.sdk.search.AddressQuery.query</a> can consist of parts of an address or full addresses, optionally comma separated. <a href="index.html">com.here.sdk.search.AddressQuery</a> should only be used to search for parts of the address, excluding the POI name. To be able to include the POI name, use <a href="../-text-query/index.html">com.here.sdk.search.TextQuery</a> instead. <a href="../-search-options/language-code.html">com.here.sdk.search.SearchOptions.languageCode</a> specifies the language of the <a href="query.html">com.here.sdk.search.AddressQuery.query</a> and determines the preferred language of the results.</p></div></div>
