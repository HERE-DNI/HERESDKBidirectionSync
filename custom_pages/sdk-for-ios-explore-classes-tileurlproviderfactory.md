<p>Creates <code><a href="../Maps.html#/s:7heresdk21TileUrlRequestHandlera">TileUrlRequestHandler</a></code> for the given URL template.
A url template should look like this ‘<a href="https://TestRasterTileService.com/%7Bz%7D/%7Bx%7D/%7By%7D/">https://TestRasterTileService.com/{z}/{x}/{y}/</a>’
here the z parameter is the storage level, x and y define the location of the tile.
The valid range for X and Y is from 0 to 2^level − 1.</p>
