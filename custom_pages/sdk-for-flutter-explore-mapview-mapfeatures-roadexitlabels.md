<div class="section desc markdown">

Show or hide road exit labels, if available.

Supported modes: <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-roadexitlabelsnumbersonly">MapFeatureModes.roadExitLabelsNumbersOnly</a>, <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-roadexitlabelsall">MapFeatureModes.roadExitLabelsAll</a>

Default mode is <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-roadexitlabelsnumbersonly">MapFeatureModes.roadExitLabelsNumbersOnly</a>.

Road exit labels are enabled by default with <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-roadexitlabelsnumbersonly">MapFeatureModes.roadExitLabelsNumbersOnly</a> on normal, lite and topo schemes and with <a href="sdk-for-flutter-explore-mapview-mapfeaturemodes-roadexitlabelsall">MapFeatureModes.roadExitLabelsAll</a> on logistics schemes. Note that topo schemes are only available in the HERE SDK Navigate variant.

Not supported for <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.satellite</a>, <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.roadNetworkDay</a> and <a href="sdk-for-flutter-explore-mapview-mapscheme">MapScheme.roadNetworkNight</a>.
