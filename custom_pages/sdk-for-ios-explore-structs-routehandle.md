# RouteHandle

<div class="declaration">

<div class="language">

``` highlight
public struct RouteHandle : Hashable
```

</div>

</div>

Provides an opaque handle to the calculated <a href="sdk-for-ios-explore-classes-route">`Route`</a>. A handle encodes the calculated route. The route can be decoded from a handle at a later point in time as long as the service uses the same map data which was used during encoding. Note that the <a href="sdk-for-ios-explore-classes-route#/s:7heresdk5RouteC11routeHandleAA0bD0VSgvp">`Route.routeHandle`</a> is provided only if <a href="sdk-for-ios-explore-structs-routeoptions#/s:7heresdk12RouteOptionsV06enableB6HandleSbvp">`RouteOptions.enableRouteHandle`</a> is set before route calculation. A `RouteHandle` generated by the online <a href="sdk-for-ios-explore-classes-routingengine">`RoutingEngine`</a> is not compatible with the <a href="sdk-for-ios-explore-classes-offlineroutingengine">`OfflineRoutingEngine`</a>. Similarly, a `RouteHandle` from the <a href="sdk-for-ios-explore-classes-offlineroutingengine">`OfflineRoutingEngine`</a> cannot be used with the online <a href="sdk-for-ios-explore-classes-routingengine">`RoutingEngine`</a>. Using an incompatible `RouteHandle` results in a <a href="sdk-for-ios-explore-enums-routingerror">`RoutingError`</a>.
