<h1>RealisticViewVectorImage class</h1></div>

<p>A realistic view of a junction.</p>
<p>The fields describing the realistic view are
<code>RealisticViewVectorImage.junctionViewSvgImageContent</code> contains a SVG image of the junction view
represented as a string.
<code>RealisticViewVectorImage.signpostSvgImageContent</code> contains an SVG image of the signpost corresponding
to the junction, also represented as a string.
A valid realistic view contains a non-empty <code>RealisticViewVectorImage.junctionViewSvgImageContent</code> and a
non-empty <code>RealisticViewVectorImage.signpostSvgImageContent</code>.
Use <code>RealisticViewWarningListener</code> to get notifications with the realistic views of the upcoming junctions.</p>
