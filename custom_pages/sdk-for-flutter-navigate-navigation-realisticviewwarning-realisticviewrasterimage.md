<p>The realistic view object for which the warning is given.
Image resources are stored as raster graphics.
Within <a href="sdk-for-flutter-navigate-navigation-realisticviewwarning-class">RealisticViewWarning</a>, only one type of image, either raster or vector, will be provided.
If this property is not <code>null</code>, then <a href="sdk-for-flutter-navigate-navigation-realisticviewwarning-realisticviewvectorimage">RealisticViewWarning.realisticViewVectorImage</a> will be <code>null</code>.
<strong>Note:</strong> Certain countries support only raster images as realistic views. Currently, this is the case
only for Japan, but in the future, more countries might support this type of realistic views.</p>
