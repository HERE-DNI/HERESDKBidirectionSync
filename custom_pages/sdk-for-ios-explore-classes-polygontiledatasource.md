Polygon tile data source allows the rendering engine access to user managed data sets of geodetic polygons and their attributes through a <a href="sdk-for-ios-explore-protocols-polygontilesource">`PolygonTileSource`</a>.

Note: This is a beta release of this feature, so there could be a few bugs and unexpected behavior. Related APIs may change for new releases without a deprecation process.
