A list of ranges. The unit is defined by the type parameter. Each range defines the maximum allowed value to reach a destination. For each value an <a href="sdk-for-flutter-navigate-routing-isoline-class">Isoline</a> is calculated indicating the reachable area. If empty, <a href="sdk-for-flutter-navigate-routing-isolineoptions-class">IsolineOptions</a> object is considered invalid.
