<h1>SpeedLimitOffset class</h1></div>
<section class="desc markdown">
<p>A class that represents two separate speed limit offsets for higher and lower speed limits.</p>
<p>A driver will be notified when the current driving speed is above the speed limit + offset.
Only one of the two offsets is used depending on the current speed limit.</p>
