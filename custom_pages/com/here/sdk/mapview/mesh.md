public final class Mesh extends [NativeBase](sdk-for-android-explore-api-reference-latestnativebase "class in com.here")
Represents a mesh in 3D space. Such meshes are built using [`MeshBuilder`](sdk-for-android-explore-api-reference-latestmeshbuilder "class in com.here.sdk.mapview").

The class is not offering any methods, as its data is only meant to be consumed internally when being passed to [`MapMarker3DModel`](sdk-for-android-explore-api-reference-latestmapmarker3dmodel "class in com.here.sdk.mapview") constructor.
