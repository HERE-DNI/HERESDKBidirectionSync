    ### onScroll

    <div class="member-signature">

    <span class="modifiers">public</span> <span class="return-type">void</span> <span class="element-name">onScroll</span><span class="parameters">(float translationX,
    float translationY)</span>

    </div>

    <div class="block">

    To be called to trigger scroll gesture handling.

    </div>

    Parameters:  
    `translationX` -

    Translation along x axis in pixels. Values > 0 are interpreted as
    translation left and values < 0 as translation right.

    `translationY` -

    Translation along y axis in pixels. Values > 0 are interpreted as
    translation up and values < 0 as translation down.
