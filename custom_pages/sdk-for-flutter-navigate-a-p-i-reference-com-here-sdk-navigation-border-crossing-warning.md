The main field describing the border crossing is <a href="type.html">com.here.sdk.navigation.BorderCrossingWarning.type</a> specifying whether the border crossing is given for a country border or a state border. The <a href="type.html">com.here.sdk.navigation.BorderCrossingWarning.type</a> must be known. The country and state codes are contained in <a href="administrative-rules.html">com.here.sdk.navigation.BorderCrossingWarning.administrativeRules</a> along with other information such as speed limits, u-turn regulations or pre-trip planning information contained by the <a href="../../com.here.sdk.mapdata/-administrative-rules/index.html">com.here.sdk.mapdata.AdministrativeRules</a>.</p><p class="paragraph">Use <code class="lang-kotlin">BorderCrossingWarningListener</code> to get notifications about upcoming country or state border crossings.</p></div></div>
