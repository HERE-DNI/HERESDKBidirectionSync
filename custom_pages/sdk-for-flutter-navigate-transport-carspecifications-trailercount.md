<div class="section desc markdown">

Defines number of trailers attached to the vehicle. The provided value must be in the range \[0, 1\]. By default, it is not set. When specifying <a href="sdk-for-flutter-navigate-transport-carspecifications-traileraxlecount">CarSpecifications.trailerAxleCount</a>, then <a href="sdk-for-flutter-navigate-transport-carspecifications-trailercount">CarSpecifications.trailerCount</a> is required and must be greater than 0.
