The duration in seconds that should be spent at a waypoint of type <a href="sdk-for-flutter-explore-routing-waypointtype">WaypointType.stopover</a>. Impacts time-aware calculations. Ignored for waypoints of type <a href="sdk-for-flutter-explore-routing-waypointtype">WaypointType.passThrough</a>. The default duration is 0 seconds.
