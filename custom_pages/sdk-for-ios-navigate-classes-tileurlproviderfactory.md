  <div class="abstract">

  Creates <a href="sdk-for-ios-navigate-maps#sdk-for-ios-navigate-s-7heresdk21TileUrlRequestHandlera">`TileUrlRequestHandler`</a> for the given URL template. A url template should look like this ‘<https://TestRasterTileService.com/%7Bz%7D/%7Bx%7D/%7By%7D/>’ here the z parameter is the storage level, x and y define the location of the tile. The valid range for X and Y is from 0 to 2^level − 1.
