## Values

<span class="name">optimizedClientMap</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-core-engine-catalogtype">CatalogType</a></span>  
Catalog type for the so-called "rest of the world" (ROW). It covers the whole world, but may contain only a base map with fewer details for regions such as Japan.

<span class="name">optimizedClientMapJapan</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-core-engine-catalogtype">CatalogType</a></span>  
Catalog type for Japan. Has to be used in combination with <a href="sdk-for-flutter-navigate-core-engine-catalogtype">CatalogType.optimizedClientMap</a>.

**Note:** This catalog type is only available on request. Please contact your HERE representative for more details. In order to load this map you need to enable your credentials with the help of the HERE team.
