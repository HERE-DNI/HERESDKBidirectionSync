# <span class="kind-class">TransportSpecification</span> class

</div>

<div class="section desc markdown">

Contains transport attributes details related to the transport mode.

**Notes**

- By default all vehicle specifications from `RoutingOptions.transport_specification` are set to `null` and the `RoutingOptions.transport_specification.transport_mode` is set to <a href="sdk-for-flutter-explore-transport-transportmode">TransportMode.car</a>.
- A route can be calculated with only the `RoutingOptions.transport_specification.transport_mode` set.
