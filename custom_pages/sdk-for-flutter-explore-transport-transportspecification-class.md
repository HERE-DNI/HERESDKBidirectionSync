<h1>TransportSpecification class</h1></div>

<p>Contains transport attributes details related to the transport mode.</p>
<p><strong>Notes</strong></p>
<ul>
<li>By default all vehicle specifications from <code>RoutingOptions.transport_specification</code> are set to
<code>null</code> and the <code>RoutingOptions.transport_specification.transport_mode</code> is set to <a href="sdk-for-flutter-explore-transport-transportmode">TransportMode.car</a>.</li>
<li>A route can be calculated with only the <code>RoutingOptions.transport_specification.transport_mode</code> set.</li>
</ul>
