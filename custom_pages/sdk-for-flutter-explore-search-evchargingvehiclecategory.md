# <span class="kind-enum">EVChargingVehicleCategory</span> enum

<div class="section desc markdown">

Represents the category of the vehicle supported at the charging point.

**Note:** This is a beta release of this feature, so there could be a few bugs and unexpected behaviors. Related APIs may change for new releases without a deprecation process.

## Values

<span class="name">regular</span> <span class="signature">→ const <a href="sdk-for-flutter-explore-search-evchargingvehiclecategory">EVChargingVehicleCategory</a></span>  
The charging location is suitable for regular passenger cars, and optionally also for light commercial vehicles, such as vans, pickups and the like, if signaled by truckAccess property. This is the default category, used when there is no explicit information about support for other vehicle types.

<span class="name">twoWheeler</span> <span class="signature">→ const <a href="sdk-for-flutter-explore-search-evchargingvehiclecategory">EVChargingVehicleCategory</a></span>  
The charging location is suitable for motor bikes, e-scooters, and the like.

<span class="name">heavy</span> <span class="signature">→ const <a href="sdk-for-flutter-explore-search-evchargingvehiclecategory">EVChargingVehicleCategory</a></span>  
The charging location is suitable for heavy vehicle charging, including, for example, rigid trucks, semi-trailer trucks, requiring more physical space for parking and maneuvering than passenger cars.
