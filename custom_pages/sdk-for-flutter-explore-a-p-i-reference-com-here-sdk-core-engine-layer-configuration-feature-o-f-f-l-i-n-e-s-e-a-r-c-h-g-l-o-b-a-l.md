<h1 class="cover">OFFLINE_<wbr/>SEARCH_<wbr/>GLOBAL</h1>
<div class="platform-hinted" data-platform-hinted="data-platform-hinted"><div class="content sourceset-dependent-content" data-active="" data-togglable=":modules:dokkaHtml/release"><div class="symbol monospace"><div class="block">/sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-feature-o-f-f-l-i-n-e-s-e-a-r-c-h-g-l-o-b-a-l</div></div><p class="paragraph">Map data used for global search indexing. This feature enables searches across broader geographic areas and improves both performance and accuracy by leveraging global search indices. By default this feature is disabled.</p><p class="paragraph">Enables the HERE SDK to use the enhanced offline search algorithm for downloaded map regions when:</p><ul><li><p class="paragraph"><code class="lang-kotlin">OFFLINE_SEARCH_GLOBAL</code> is included in /sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-enabled-features and</p></li><li><p class="paragraph">downloaded map regions contain the required OCM layer groups listed below.</p></li></ul><p class="paragraph">Also enables the enhanced offline search algorithm for implicitly prefetched map content when:</p><ul><li><p class="paragraph"><code class="lang-kotlin">OFFLINE_SEARCH_GLOBAL</code> is included in /sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-implicitly-prefetched-features and</p></li><li><p class="paragraph">downloaded map regions (if present) contain the required OCM layer groups.</p></li></ul><p class="paragraph">Both options can be enabled together. However, if enabling the feature for implicitly prefetched content, it is recommended to also enable it for downloaded map regions to ensure consistent search behavior.</p><p class="paragraph"><strong>Important</strong>: After enabling this feature, make sure to update the cached offline maps. If the cached maps are not updated, the algorithm will either:</p><ol><li><p class="paragraph">Fall back to the stable offline search if <code class="lang-kotlin">OFFLINE_SEARCH</code> is still included in /sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-enabled-features, or</p></li><li><p class="paragraph">Produce a <code class="lang-kotlin">LAYERS_NOT_DOWNLOADED</code> error if the necessary layers are missing.</p></li></ol><p class="paragraph">To prevent excessive map size growth, it is recommended to enable only one of <code class="lang-kotlin">OFFLINE_SEARCH_GLOBAL</code> or <code class="lang-kotlin">OFFLINE_SEARCH</code> at a time.</p><p class="paragraph">Enabling this feature increases storage requirements:</p><ul><li><p class="paragraph">Downloaded map region size by ~11–16% when enabled via /sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-enabled-features.</p></li><li><p class="paragraph">Map cache size by ~40–140% when enabled via /sdk-for-flutter-explore-a-p-i-reference-com-here-sdk-core-engine-layer-configuration-implicitly-prefetched-features (upper bound occurs for long routes, e.g., Paris → Rome).</p></li></ul><p class="paragraph">Feature enables following OCM layer groups:</p><ul><li><p class="paragraph">"search_global"</p></li><li><p class="paragraph">"search_data"</p></li></ul><p class="paragraph">Note: This is a beta release of this feature, so there could be a few bugs and unexpected behaviors. Related APIs may change for new releases without a deprecation process.</p></div></div>
