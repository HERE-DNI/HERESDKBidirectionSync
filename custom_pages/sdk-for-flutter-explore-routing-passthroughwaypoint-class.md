# <span class="kind-class">PassThroughWaypoint</span> class

</div>

<div class="section desc markdown">

This structure provides all the information for a passthrough waypoint.

The location information and offset of the waypoint are stored in `PassThroughWaypoint.place` and <a href="sdk-for-flutter-explore-routing-passthroughwaypoint-offset">PassThroughWaypoint.offset</a> respectively.
