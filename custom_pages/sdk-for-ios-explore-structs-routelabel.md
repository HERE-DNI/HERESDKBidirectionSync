# RouteLabel

<div class="declaration">

<div class="language">

``` highlight
public struct RouteLabel : Hashable
```

</div>

</div>

The main street name or road number for a route. A route can contain more than one such street name or route number. To include route labels in the route response, enable it using <a href="sdk-for-ios-explore-structs-routeoptions#sdk-for-ios-explore-s-7heresdk12RouteOptionsV06enableB6LabelsSbvp">`RouteOptions.enableRouteLabels`</a>.
