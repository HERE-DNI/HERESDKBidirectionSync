# <span class="kind-enum">NavigabilityType</span> enum

</div>

<div class="section desc markdown">

Represents the navigability level of a map region.

This enum defines whether a region can be used for navigation purposes. It helps categorize regions based on their usability in routing and map operations.

</div>

## Values

<span class="name">nonNavigable</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-maploader-navigabilitytype">NavigabilityType</a></span>  
Region is not suitable for navigation. Indicates that the region lacks sufficient data for routing or turn-by-turn navigation. Such regions may only provide basic map display or limited functionality.

<span class="name">navigable</span> <span class="signature">→ const <a href="sdk-for-flutter-navigate-maploader-navigabilitytype">NavigabilityType</a></span>  
Region is suitable for navigation (default navigability type). Indicates that the region contains complete data required for routing and navigation use cases. This is the default value for most regions.
