<span class="name"><a href="sdk-for-flutter-navigate-navigation-bordercrossingwarningoptions-filteroutstateborderwarnings">filterOutStateBorderWarnings</a></span> <span class="signature">↔ bool</span>  
If set to `true`, all the state border crossing notifications will not be given. If the value is `false`, all border crossing notifications will be given for both country borders and state borders. By default, the <a href="sdk-for-flutter-navigate-navigation-bordercrossingwarningoptions-filteroutstateborderwarnings">BorderCrossingWarningOptions.filterOutStateBorderWarnings</a> is set to `true`.

<span class="name"><a href="sdk-for-flutter-navigate-navigation-bordercrossingwarningoptions-includecommercialvehicleregulations">includeCommercialVehicleRegulations</a></span> <span class="signature">↔ bool</span>  
If set to `true`, commercial vehicle regulations data will be included in border crossing warnings when available. If set to `false`, the commercial vehicle regulations field will be stripped from warnings even if the data is available in the map. By default, this is set to `false`. This is useful for commercial vehicles that need CVR information - they should explicitly enable it.
