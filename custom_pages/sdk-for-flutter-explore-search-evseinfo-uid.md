Uniquely identifies the EVSE within the CPOs platform (and suboperator platforms). For example a database ID or the actual "EVSE ID". This field can never be changed, modified or renamed. This is the 'technical' identification of the EVSE, not to be used as 'human readable' identification, use the field <a href="sdk-for-flutter-explore-search-evseinfo-id">EVSEInfo.id</a> for that.
