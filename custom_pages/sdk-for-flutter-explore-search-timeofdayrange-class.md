# <span class="kind-class">TimeOfDayRange</span> class

</div>

<div class="section desc markdown">

Time period when the tariff element is valid, in local time.

The time period wraps around to the next day, when end time of the period <a href="sdk-for-flutter-explore-search-timeofdayrange-to">TimeOfDayRange.to</a> is smaller than the beginning <a href="sdk-for-flutter-explore-search-timeofdayrange-from">TimeOfDayRange.from</a>. **Note:** This is a beta release of this feature, so there could be a few bugs and unexpected behaviors. Related APIs may change for new releases without a deprecation process.
