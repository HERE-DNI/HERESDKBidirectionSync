# <span class="kind-class">TollStructure</span> class

</div>

<div class="section desc markdown">

A class that defines tolling configuration for a lane.

It describes which types of toll structures apply and the acceptable payment methods. This information can be used to guide drivers through toll roads based on their preferences or vehicle capabilities.

**Note:** This is a beta release of this feature, so there could be a few bugs and unexpected behaviors. Related APIs may change for new releases without a deprecation process.
