<h1>DrawOrderType enum</h1>
</div>

<p>Specifies the type of map item draw order.</p>
<p>Map item rendering behavior is chosen based on the draw order type.</p>
<p>Regardless of a draw order type map items with a higher draw order are drawn on top of map items with a lower draw order.</p>
<p>When having map items in a scene with the same draw order, but with different draw order types
<a href="/sdk-for-flutter-navigate-mapview-drawordertype">DrawOrderType.mapSceneAdditionOrderDependent</a> and <a href="/sdk-for-flutter-navigate-mapview-drawordertype">DrawOrderType.mapSceneAdditionOrderIndependent</a>,
<a href="/sdk-for-flutter-navigate-mapview-drawordertype">DrawOrderType.mapSceneAdditionOrderDependent</a> items will be rendered on top of <a href="/sdk-for-flutter-navigate-mapview-drawordertype">DrawOrderType.mapSceneAdditionOrderIndependent</a>
ones.</p>
