Indicates the index of the last traveled route section. When it is provided, the previous sections are discarded from the refreshed route and the starting point is searched in the provided section. If the starting point is not found in that section an <a href="sdk-for-flutter-navigate-routing-routingerror">RoutingError.couldNotMatchOrigin</a> error is triggered.
