<h1>AuthenticationMode class abstract</h1></div>
<section class="desc markdown">

header ("Authorization", "Bearer $Token") to each online request of the
module the object is added to.</p>
<p>The token (if used) can be provided or is
retrieved via key/secret from a dedicated backend.</p>
