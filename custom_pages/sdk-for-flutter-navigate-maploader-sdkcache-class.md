<h1>SDKCache class abstract</h1></div>

<p>A class to manage SDK Cache.</p>
<p>Path for SDKCache is specified via <a href="sdk-for-flutter-navigate-core-engine-sdkoptions-cachepath">SDKOptions.cachePath</a>.
SDKCache manages temporary downloaded map data during map interaction and follows LRU (least recently used) strategy to delete
map data when cache size exceeds the specified <a href="sdk-for-flutter-navigate-core-engine-sdkoptions-cachesizeinbytes">SDKOptions.cacheSizeInBytes</a>.</p>
