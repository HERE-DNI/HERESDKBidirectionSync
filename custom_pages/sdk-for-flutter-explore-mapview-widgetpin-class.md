<h1>WidgetPin class abstract</h1></div>

<p>Controller for a <code>Widget</code> pinned at a fixed geographical location on the map.</p>
<p>A pinned Widget tracks the geographical location as the map is being
manipulated. It behaves like a <a href="sdk-for-flutter-explore-mapview-mapmarker-class">MapMarker</a>, only it's a regular
Flutter Widget and is not part of normal map rendering.</p>
<p>WidgetPin allows modifying the geographical location of the pinned Widget
as well as its placement relative to it.</p>
<p>Use <a href="sdk-for-flutter-explore-mapview-heremapcontroller-pinwidget">HereMapController.pinWidget</a> to pin (add) a <code>Widget</code> to a map and obtain
in instance of <a href="sdk-for-flutter-explore-mapview-widgetpin-class">WidgetPin</a> that controls it.</p>
<p>To unpin (remove) a Widget from the map, use <a href="sdk-for-flutter-explore-mapview-heremapcontroller-unpinwidget">HereMapController.unpinWidget</a>.
or <a href="sdk-for-flutter-explore-mapview-widgetpin-unpin">WidgetPin.unpin</a>.</p>
