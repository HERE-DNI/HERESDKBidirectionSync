<div class="section desc markdown">

Creates a default set of styling options for the text of a <a href="sdk-for-flutter-navigate-mapview-mapmarker-class">MapMarker</a> that consists of the following values:

- Text size: 18 pixels
- Text color: opaque white
- Text outline size: 0 pixels
- Text outline color: opaque black
- Text placement: <a href="sdk-for-flutter-navigate-mapview-mapmarkertextstyleplacement">MapMarkerTextStylePlacement.bottom</a>

Once the resulting `TextStyle` is applied to a `MapMarker`, its text will be centered over its image.

The font will be 18 pixels wide, colored opaque white and will have no visible outline.
