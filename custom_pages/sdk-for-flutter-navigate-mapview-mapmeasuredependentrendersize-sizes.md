<div class="section desc markdown">

The dictionary describing the size (value) per map measure (key).

Units of keys and values are defined in <a href="sdk-for-flutter-navigate-mapview-mapmeasuredependentrendersize-measurekind">MapMeasureDependentRenderSize.measureKind</a> and <a href="sdk-for-flutter-navigate-mapview-mapmeasuredependentrendersize-sizeunit">MapMeasureDependentRenderSize.sizeUnit</a>.

`sizes` with a single entry indicates using a fixed size value across all map measures.

</div>

final Map<double, double> sizes;
