# <span class="kind-class">RouteLabel</span> class

</div>

<div class="section desc markdown">

The main street name or road number for a route.

A route can contain more than one such street name or route number. To include route labels in the route response, enable it using <a href="sdk-for-flutter-explore-routing-routeoptions-enableroutelabels">RouteOptions.enableRouteLabels</a>.
