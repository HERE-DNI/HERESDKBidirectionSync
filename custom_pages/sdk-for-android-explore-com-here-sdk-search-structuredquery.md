<div class="block">

The options to specify a structured query. Only supported in
OfflineSearchEngine (only available for the Navigate license). Note:
This is a beta release of this feature, so there could be a few bugs and
unexpected behaviors. Related APIs may change for new releases without a
deprecation process.
