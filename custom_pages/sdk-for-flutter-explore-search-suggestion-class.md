<h1>Suggestion class abstract</h1></div>

<p>Suggestion is meant to provide relevant suggestions to partial queries, like "restaur", "starbu", "eiffel".</p>
<p>Represents a relevant response to user queries.
Suggestions (please check <a href="sdk-for-flutter-explore-search-suggestiontype">SuggestionType</a>) are either:
Place: <a href="sdk-for-flutter-explore-search-suggestiontype">SuggestionType.place</a>
Query: <a href="sdk-for-flutter-explore-search-suggestiontype">SuggestionType.chain</a> or <a href="sdk-for-flutter-explore-search-suggestiontype">SuggestionType.category</a></p>
<p>With "Place" you get data for a concrete place in the world.
With "Query" something to follow-up, a way to perform more focused search.</p>
