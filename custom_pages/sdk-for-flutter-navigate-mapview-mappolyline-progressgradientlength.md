To achieve a constant gradient length, use /sdk-for-flutter-navigate-mapview-mapmeasuredependentrendersize-class
with a single value. To achieve a gradient length dependent on map zoom,
use /sdk-for-flutter-navigate-mapview-mapmeasuredependentrendersize-class with multiple values. The default value is a constant
gradient length of zero pixels. The gradient is guaranteed to fit into polyline, i.e. the
actual gradient can be shorter then <code>progressGradientLength</code>.</p>
