<h1>RouteHandle class</h1></div>

<p>Provides an opaque handle to the calculated <a href="/sdk-for-flutter-explore-routing-route-class">Route</a>.</p>
<p>A handle encodes the calculated route. The route can be decoded from a handle at a
later point in time as long as the service uses the same map data which was used during encoding.
Note that the <a href="/sdk-for-flutter-explore-routing-route-routehandle">Route.routeHandle</a> is provided only
if <a href="/sdk-for-flutter-explore-routing-routeoptions-enableroutehandle">RouteOptions.enableRouteHandle</a> is set before route calculation.
A <code>RouteHandle</code> generated by the online <code>RoutingEngine</code> is not compatible with the <code>OfflineRoutingEngine</code>.
Similarly, a <code>RouteHandle</code> from the <code>OfflineRoutingEngine</code> cannot be used with the online <code>RoutingEngine</code>.
Using an incompatible <code>RouteHandle</code> results in a <a href="/sdk-for-flutter-explore-routing-routingerror">RoutingError</a>.</p>
