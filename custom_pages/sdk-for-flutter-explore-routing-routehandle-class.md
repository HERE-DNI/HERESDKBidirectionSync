<h1>RouteHandle class</h1></div>
<section class="desc markdown">
<p>Provides an opaque handle to the calculated <a href="../routing/Route-class.html">/sdk-for-flutter-explore-routing-route-class</a>.</p>
<p>A handle encodes the calculated route. The route can be decoded from a handle at a
later point in time as long as the service uses the same map data which was used during encoding.
Note that the <a href="../routing/Route/routeHandle.html">/sdk-for-flutter-explore-routing-route-routehandle</a> is provided only
if <a href="../routing/RouteOptions/enableRouteHandle.html">/sdk-for-flutter-explore-routing-routeoptions-enableroutehandle</a> is set before route calculation.
A <code>RouteHandle</code> generated by the online <code>RoutingEngine</code> is not compatible with the <code>OfflineRoutingEngine</code>.
Similarly, a <code>RouteHandle</code> from the <code>OfflineRoutingEngine</code> cannot be used with the online <code>RoutingEngine</code>.
Using an incompatible <code>RouteHandle</code> results in a <a href="../routing/RoutingError.html">/sdk-for-flutter-explore-routing-routingerror</a>.</p>
</section>
